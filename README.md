# AI Prompt Guide — איך לדבר עם AI כדי לקבל תוצאות טובות באמת

מיני-אפליקציה אינטראקטיבית בעברית שמלמדת כיצד לנסח בקשות לכלי AI כדי לקבל תוצאות טובות יותר.

---

## מה זה?

חוויית למידה קצרה ופרקטית של 10 מסכים:

1. מסך פתיחה
2. למה AI לא נותן תוצאות טובות?
3. הטעות הכי נפוצה
4. הנוסחה לפרומפט טוב
5. **תרגול אינטראקטיבי** — בניית פרומפט בחינם
6. דוגמאות לפני ואחרי
7. שימושים יומיומיים
8. **תרגול אינטראקטיבי** — בחירת סוג ויצירת תבנית
9. בנק תבניות מוכן להעתקה (10 תבניות)
10. מסך סיום + CTA

## הרצה מקומית

### אפשרות A — פתיחה ישירה בדפדפן (ללא שרת)

פשוט לפתוח את `index.html` בדפדפן.

> **שים לב:** פונקציית "העתקה" דורשת HTTPS או `localhost`. בפתיחה מקובץ (`file://`) היא עשויה לא לעבוד בכל הדפדפנים. במקרה כזה, השתמש באפשרות B.

### אפשרות B — שרת מקומי (מומלץ)

דורש [Node.js](https://nodejs.org/) מותקן.

```bash
# התקנה חד-פעמית
npm install

# הפעלת שרת פיתוח (נפתח בכתובת http://localhost:3000)
npm start
```

או ישירות ללא התקנה:

```bash
npx serve -l 3000 .
```

## דרישות טכניות

- דפדפן מודרני (Chrome, Firefox, Safari, Edge)
- Node.js 14+ (רק אם משתמשים בשרת מקומי)
- אין תלויות חיצוניות, אין build step, אין framework

הגופן (Heebo) נטען מ-Google Fonts. אם אין גישה לאינטרנט, הדפדפן יחזור לגופן ברירת מחדל עברי.
